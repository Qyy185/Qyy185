## 项目

### 🗺️ 旅游行程规划系统 · 知识库检索增强（毕业设计）

> LangChain 1.x + LangGraph + Chroma + 通义千问 + Gradio 6 ｜ **7 347 行** ｜ 独立开发

> 论文题目：《基于知识库检索的旅游行程规划系统》

用户输入目的地、天数、预算、人数与兴趣偏好，Agent 先检索本地知识库，再融合真实资料生成结构化行程并**标注引用来源**。

- 知识库 **103 份** Markdown（56.9 万字），覆盖 **34 个省级行政区**，切分成 **2 309** 个向量片段
- **差异化切片**：Markdown 按标题层级 / JSON 结构化数据 / 纯文本递归字符，三类资料三套策略
- **187 张实景图册**按 6 类兴趣标签召回回填，弱网下也不影响排版
- 输出四件套：预算条 / 行李清单 / 交通方案 / 日历导出（`.ics`）
- 双入口（CLI / Gradio），支持局域网与公网访问、二维码分享海报
- 代码从实训初版 **489 行迭代到 7 347 行**，历时 5 个月

[`TourismPlanner`](https://github.com/Qyy185/TourismPlanner)

### 📅 现代日历应用 · 前端工程 + AI 集成

> 原生 JavaScript (ES6 Class) + Tailwind CSS v3 + localStorage ｜ **运行时零依赖 / 零构建**

打开 `index.html` 就能用，不需要服务器、不需要打包。

- **月 / 周 / 日三视图**（侧边栏工作台布局）+ 深色模式 + 按日笔记 + 多条日程
- **月视图格子里直接显示日程条**，不用点进去才知道当天有什么
- **全文搜索**（`/` 唤起）+ **键盘快捷键**（T/M/W/D/←→/N）
- **RFC 5545 日历互导**：完整实现 `.ics` 解析与生成，**与我的毕业设计项目双向互通**，导出的文件可直接进手机 / 系统日历
- **AI 月度摘要**：把当月笔记交给通义千问生成回顾，无 Key 时优雅降级
- **69 个单元测试，覆盖率 86.5%**（日期算法 100% / ics 95.75% / 事件存储 92.59%），CI 自动跑
- 十个模块职责单一，纯逻辑与 DOM 分离，所以核心逻辑能直接跑单测
- README 记录了 **7 个真实踩坑**（日期 0-based、UTC 时区偏移、自动保存竞争、Tailwind 优先级冲突、v8 覆盖率归因、响应式断点、RFC 5545 折行）

> 原为三人合作的软件开发课程设计，**v2 由我主导重构**（界面重做、架构拆分、补测试与 CI、新增上述功能）。
